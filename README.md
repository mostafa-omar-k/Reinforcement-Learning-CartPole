# CartPole Reinforcement Learning

A Python Reinforcement Learning project that trains an agent to balance a pole on a moving cart using the **CartPole-v1** environment.

## Algorithms

* **Q-Learning** — learns the optimal action using the best estimated future reward.
* **SARSA** — updates the Q-value based on the action actually selected by the current policy.
* **Monte Carlo** — updates Q-values using the total reward collected throughout an episode.

## Main Concepts

* Reinforcement Learning
* Q-Table
* Epsilon-Greedy Exploration
* State Discretization
* Q-Learning
* SARSA
* Monte Carlo Learning
* Reward Tracking

## Environment

**Gym CartPole-v1**

The agent controls the cart by moving it left or right while trying to keep the pole balanced.
